# Python Practice

A collection of small beginner Python programs I wrote while learning the fundamentals and strengthening my programming concepts.

Each file is a standalone, interactive console program.

## How to run

You need Python 3 installed. From this folder:

```bash
python 07_rock_paper_scissors.py
```

(On some systems use `python3` instead of `python`.)

## Programs

| File | What it does | Concepts practiced |
|---|---|---|
| `01_nursery_inquiry.py` | Admission inquiry for a nursery, with section and price choice | `input`, `if / elif / else` |
| `02_door_adventure.py` | Text adventure: choose a door, then a box | Nested conditions |
| `03_favorite_colors.py` | Collects favorite colors into a list | Lists, `append` |
| `04_library_wishlist.py` | Manage a library and a wishlist, merge and donate books | Lists, `remove`, membership checks |
| `05_whose_wallet.py` | Picks a random person to pay for dinner | `random.choice`, `split`, f-strings |
| `06_rabbit_palace.py` | Place a rabbit on a 3x3 grid | Nested lists, indexing |
| `07_rock_paper_scissors.py` | Rock Paper Scissors against the computer, with ASCII art | `random`, conditions, multi-line strings |
| `08_attendance_check.py` | Confirm attendance for a list of people | `for` loop, `split` |
| `09_travel_list.py` | Ask which countries on a list you have visited | `for` loop, f-strings |
| `10_daily_tasks.py` | Track done and ongoing tasks for the day | Loops, two lists |
| `11_ishop_calculator.py` | Basket calculator that totals item prices | `range`, `float`, `sum` |
| `12_football_academy.py` | Registration flow for a football academy | `input`, nested conditions |
| `13_password_generator.py` | Builds a password from letters, numbers, and symbols | `random.choices`, `string`, `shuffle` |
| `14_calculator.py` | Simple calculator that repeats until you stop | Functions, `while` loop |
| `15_number_guessing.py` | Guess a number in 7 tries | `while`, `random.randint`, lists |
| `16_hangman.py` | Classic Hangman with ASCII stages | `while`, lists, string handling |
